# 🌸 Iris Flower Classification using KNN

## 📌 Project Overview

This project classifies Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

using the K-Nearest Neighbors (KNN) Machine Learning algorithm.

---

## 🛠 Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

---

## 📂 Dataset

The project uses the built-in Iris Dataset from Scikit-learn.

- 150 Samples
- 4 Features
- 3 Classes

---

## 🚀 Workflow

1. Load Dataset
2. Train-Test Split
3. Feature Scaling
4. Train KNN Model
5. Predict Species
6. Evaluate Performance
7. Plot Confusion Matrix

---

## 📊 Results

- Accuracy: **100%**
- F1 Score: **1.0**
